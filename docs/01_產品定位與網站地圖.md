# 01｜產品定位、資訊架構與讀者動線

## 1. 使用者與產品目標

**主要讀者：** 從 IG、Spotify、Vocus、搜尋引擎、出版書籍連結進入的繁體中文讀者；可能以手機閱讀。  
**作者需求：** 保有內容主權、能展示文章／Podcast／書籍，讓每週更新不必重新複製全篇，保留留言與私人來信管道。  
**核心目標：** 好看、好讀、容易找作品、穩定管理、一篇作品串起多平台。

優先衡量：文章閱讀可用性、找到指定作品所需步數、跨媒體連結正確率、每篇作品網站更新的人工操作量、行動裝置效能。不以空泛的停留時間或特效數量當唯一成功指標。

## 2. 內容分類的三個獨立軸線

- **作品類型 `content_type`**：`fansiwei`（凡思維研究短篇）、`longform`（深度文章）、`fiction`（原創小說／短篇）、`book`（出版書籍）；Podcast 可獨立存在，但與其他作品共用 `work_id` 關聯。
- **主題 `topics`**：心理學、神經／醫學、科學、歷史、哲學、書籍、影劇、人生等，以正式受控標籤表管理；允許單篇多個主題，作者確認後發布。
- **媒介 `media`**：`web_article`, `instagram_carousel`, `vocus_article`, `podcast_episode`, `book_page`，用於顯示或隱藏入口，**不能誤當分類**。

推薦內容採作者手動指定 `related_work_ids` 優先，可依已確認主題補充次要推薦，但絕不能產生不存在的作品或未公開作品連結。

## 3. 全站路由（GitHub Pages 的 base path 由框架統一處理）

- `/`：繪本互動 Hero、最新作品、精選文章、Podcast、出版書架、作者介紹。
- `/articles/`：所有公開文章、篩選、搜尋與排序。
- `/articles/{slug}/`：完整書面正文；依 `content_type` 渲染兩套模板；其他平台連結、延伸閱讀、留言。
- `/topics/`：主題索引。
- `/topics/{topic_slug}/`：主題文章合集。
- `/podcast/`：節目介紹與已發布單集、官方收聽連結。
- `/podcast/{episode_slug}/`：單集介紹、Spotify 播放器、對應文章與相關單集；若尚未有 Spotify URL，以外連或待同步狀態處理，不假播放器。
- `/works/`：書架首頁、已出版、原創故事、系列篩選。
- `/works/{slug}/`：真實書封、出版資料、正式介紹、試讀（作者核准後顯示）、外站連結、關聯作品、留言。
- `/works/{slug}/world/`：**有核准資料時才存在**，沒有公開世界觀素材即隱藏。
- `/about/`：作者介紹、公開歷程與作品年表。
- `/contact/`：私人來信與合作入口。
- `/privacy/`：隱私說明、第三方嵌入／留言／表單資料用途。
- `/404/`：帶可用搜尋與回首頁的友善錯誤頁。

`首頁｜探索文章｜凡思聲｜小說與出版｜關於作者` 為固定主選單。搜尋、聯絡、Instagram、Spotify、Vocus 等保留明確外連入口；手機選單不得藏住重要項目。

## 4. 首頁五大場景（視覺敘事名稱／可理解的導航標籤）

1. 思想的花園 → **凡思維**。
2. 聲音的房間 → **凡思聲**。
3. 故事的長廊 → **深度文章**。
4. 想像的國度 → **小說與出版**。
5. 作者的書桌 → **關於作者／聯絡**。

敘事場景名稱作為插畫概念，可微調；正式點擊名稱保持清楚。五場景並非網站唯一路徑，普通文字選單與搜尋一直有效。

## 5. 三條核心讀者動線

**A. IG → 網站文章 → Podcast → 相關作品**  
單一作品頁提供完整文章、IG 原貼文網址、Spotify 播放器與相關作品。任何外部連結未知時隱藏，不顯示失效連結。

**B. Spotify → 節目列表／網站單集頁 → 對應文章**  
Podcast 可有專屬單集標題，未必與文章同名。透過 `work_id` 與 `episode_guid` 明確關聯；若未配對，仍允許單集獨立列出。

**C. 搜尋／首頁 → 小說書架 → 書籍介紹 → 外部購書／原創試讀**  
從真實書封進入作品介紹，作品各自有獨立氛圍；試讀、番外、人物世界等需作者授權才公開。

## 6. 出版與編輯邊界

- 作者自行將 IG、Vocus、Spotify 發布；網站不代理登入或代發。
- 對話／本機 Codex／GitHub 不存在無設定的自動同步；建立明確的「同步網站」工作流程。
- 原稿、圖片、研究資料、人物與作者資訊不得由 Codex 補寫成真實已公開內容。
- 為了閱讀而做的字體、段落、目錄與圖片排版，不得改變書面母稿的敘事與結論。
- 網站優先採全文可選取的文字排版；IG 截圖不取代網站正文。
