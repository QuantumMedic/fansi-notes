# 02｜視覺系統與首頁互動規格

## 1. 視覺核心

**可探索的平面繪本（首頁）＋成熟文學雜誌（內頁）。** 以紙張紋理、低彩度色塊、繪本筆觸、細膩分層、局部光影構成 2.5D；避免照片拼貼、過度電影 CG、過量玻璃擬態、濃重粒子特效、喧賓奪主的自動動畫。

雙品牌層次：網站主識別《凡思筆記》，同時清楚呈現經作者核准的公開署名；《凡思聲》在 Podcast 區有獨立識別；出版書籍採原書封，不套同一種封面皮膚。

### 待定版色彩提案（Codex 可先做設計 Token，不宣稱是最終品牌色）

| 用途 | 暫定色 | 說明 |
|---|---|---|
| `paper` | `#F4EFE6` | 暖紙白背景 |
| `ink` | `#373A39` | 內文與導覽 |
| `parchment` | `#D8C5A6` | 書頁、區塊 |
| `sage` | `#82978B` | 科學與花園 |
| `bronze` | `#AC835C` | 暖色點綴 |

請使用 CSS 變數／design tokens，讓後續可替換。字體優先繁體中文顯示品質、清楚字重與安全 fallback；**不可使用未授權商用字體**。正文桌機欄寬約 680–760px；行距、段距須適合繁體中文。高對比且可用鍵盤聚焦樣式優先於裝飾。

## 2. 首頁 Hero 場景構圖

- 上方可看見 Logo／品牌、簡短描述、探索入口；**書在畫面中央偏下展開**，每區都是連續地景的一部分。
- 書頁與世界以圖層拆分：遠背景、書頁基底、五個場景、前景裝飾、hover 高亮、入口文字。所有按鈕與文字盡量是 HTML，可存取、可翻譯、可選取；插畫只是視覺。
- **凡思維／思想花園：** 葉片、研究筆記、分岔線條。Hover 單一「葉片舒展」。
- **凡思聲／聲音房間：** 暖燈、聲紋、麥克風或音訊物件。Hover 單一「燈光微亮」。
- **深度文章／故事長廊：** 書架、閱讀長廊、紙頁與投影光線。Hover「書頁微掀」。
- **小說與出版／想像國度：** 門、紙雕城市、遠方異世界剪影。Hover「門內燈光微亮」。
- **作者／作者書桌：** 筆記、筆與信封。Hover「信封／桌燈微回應」。

五場景具有不同辨識物件，但整幅圖使用同一透視角度、紋理與照明。主畫面不應像五張互不相關的功能卡拼貼。

## 3. 互動狀態與規則

| 狀態 | 行為 |
|---|---|
| 初始 | 使用者能立即辨識品牌、主內容與分類入口；不需要操作教學 |
| Pointer move | 背景、書頁、場景略微視差，幅度克制，不妨礙點擊 |
| Hover／Focus | 區域高亮，浮出名稱、簡述、最多兩個**已公開**作品預覽 |
| Click／Enter | 導覽進入分類／文章，輕微淡入淡出；正常瀏覽器返回有效 |
| Keyboard | 五個熱區均可 Tab 到達、Enter 開啟，Focus 有清楚邊框與文字 |
| Touch | 不靠 Hover；用可見文字卡片／大點擊區，點一下就進入 |
| Reduced motion | 停止視差、呼吸與紙張動作，所有內容與入口保持可用 |
| 網速慢／動畫失敗 | 靜態主插畫與完整文字導覽仍然可讀可點 |

避免強制捲動、3D WebGL 為必要依賴、阻擋首屏閱讀的動畫或播放音效。首頁裝飾不自動發聲。

## 4. 往下捲動後的編輯式首頁

建議順序：最新公開文章 → 探索主題 → 代表作品 → 最新 Podcast → 出版書架精選 → 作者短介紹 → 來信入口／頁尾。

- 最新作品以網站公開日期排序，不依文章草稿日期。
- 精選作品由作者指定順序，可保留固定代表作。
- 主要圖片採比例一致的圖片槽並支援作品專屬封面；不能自動用封面圖取代所有內頁圖。

## 5. 兩種文章模板

**深度文章 `longform`：** 插畫比重較大；舒緩留白、編輯式標題、長文目錄與章節。  
**凡思維 `fansiwei`：** 標題與研究背景更集中，封面不過度佔屏；正文末可呈現來源、研究資訊。

所有文章以同一套易讀繁體中文排版與作者識別構成，不變成兩個互不相干的網站。

## 6. 小說與出版

書架是入口：真實書封、紙張微深度、hover 輕抽出；進入各本書後，允許在既有核心設計系統上換成該作品的視覺主題。**首次開發用明確標示的示意圖**，拿到作者提供的真實書封才可正式公開。

## 7. 視覺資產準備規格

- 需要一張完整首頁構圖，以及可分層的透明前景／背景素材，便於 Codex 做輕量視差。插畫可以在設計核准後由作者／助理獨立生成；不可把文字與 Logo 燒在底圖裡。
- 每個作品封面、Podcast 方形封面和出版社真實封面使用各自資產，記錄來源、授權與 ALT；缺失時用清楚 placeholder。
- 避免把尚未公開的 IG 圖卡或書籍封面上傳到**公開** GitHub。上線圖像先由作者核准。

## 8. 響應式與無障礙

- 桌機：完整互動插畫及編輯式模組。
- 平板：縮減景深、主區域仍可點選。
- 手機：簡化場景＋清楚的分類卡，不靠 Hover 才能看名稱。
- 對比、焦點、可點尺寸、圖片替代文字、表單標籤、跳至內容連結要完整。
- 核心閱讀頁不依賴 JavaScript；動畫層失敗也能正常開啟文章。
