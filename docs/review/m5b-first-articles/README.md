## 連結與原文驗證

- 意志力的Spotify原文外連實際開啟「當你越努力，反而越快失敗？心理學怎麼看意志力的真相？」；反脆弱的Apple原文外連實際開啟《凡思聲》反脆弱單集。按鈕分別為「Spotify 收聽」及「Apple Podcasts」，不沿用原圖說「收聽Podcast全集」作為按鈕名稱。
- 單集名稱僅以來源連結中的精確平台單集識別對照既有RSS展示資料；沒有依標題猜測、建立GUID配對或自動反向文章連結。沒有核准GUID時不增加播放器。
- 原文圖說中單獨的Podcast宣傳連結在呈現層移至文末；原文字與URL在原稿及產物的隱藏來源標記中保留，只有文末保留可點href，沒有重複連結。研究文獻、圖源及一般引用不搬移；意志力原稿的宣傳句亦保留。
- 核准配對時，顯示正式單集名稱、已有Spotify／Apple連結及選擇載入式播放器；同一平台單集與原文來源重複時去重。未點選不載入iframe。沒有收聽連結則整區省略。
- Vocus／Instagram只在文末出現一次，沒有的欄位省略，皆無則省略整區。三篇只有真實Vocus；四平台測試網址只存在tests/fixtures及暫存建置，正式dist沒有測試路由。
- 桌機／手機四平台實測高度、字級、padding、邊框及圓角完全一致；390px無橫向溢出。三入口仍為3／1／2篇，合成作品排除及小說空狀態不變。

42項測試通過、型別檢查零問題、正式build50頁。原文正規化文字雜湊一致；新增連結目的辨識、去重、來源保留、無資料隱藏與隔離四平台元件驗證。沒有下載圖片、搜尋IG、重寫摘要、匯入新文、合併或部署。

## 原文完整性與資料邊界

來源連結、作者、發布與更新時間、全文雜湊、原文外部連結證據見 [source-verification.json](source-verification.json)。從指定頁面的 Lexical 正文轉成可選取的 HTML 文字，再獨立對照來源渲染 HTML：正規化空白後逐字一致；建置後測試再次驗證同一雜湊。原段落、標題、強調、清單、圖片文字說明和結尾保留。metadata 摘要直接採原文第一段，未另行摘要或改寫。

三筆 work_id 由各自唯一 Vocus 來源 ID 建立。作者署名使用來源「凡思筆記」，日期取來源 lastPublishAt／editAt，未編造缺失資料。圖片位置標記保留於原文檔案，但閱讀介面不顯示提示或空框；原文圖說保留，無圖片檔、遠端圖片嵌入或測試封面。原文既有 Spotify／Apple 外連仍留在正文，僅作來源證據，不代表核准 RSS GUID 配對。

前台中央字典只有凡思維與文章與故事，後者涵蓋 longform 和 special。原 longform／special 路徑保留靜態轉址；舊文章查詢參數仍可用。小說、九主題、25集 proposed 狀態與既有關聯架構不變。開發模式仍能看到明示待審核的 Podcast 分類；正式 build 不使用 proposed 分類。
