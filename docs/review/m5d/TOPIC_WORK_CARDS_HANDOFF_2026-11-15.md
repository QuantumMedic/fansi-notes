# M5-D｜主題頁篩選、統一作品卡片交接規格（2026-11-15）

**性質：已知當前缺陷 + 下一輪 M5-D 已排定的正式作品關聯整合。** 本文件供 Codex 依已核准資料實作與針對性驗收；目前只實作了主題頁篩選修復，**沒有實作或核准新的作品關聯**。

## 一、已確認的現況與原因

- `/series/stories/` 使用 `ArticleBrowser.astro` + `WorkCard.astro`：文章列表採雙欄，僅收錄文章。
- `/topics/[slug]/` 使用 `WorkExplorer.astro` + `UnifiedWorkCard.astro`：作品清單採單欄，探索文字與音訊。
- `catalog()` 的 `buildWorks()` 以正式 `work_id` 合併文章與 Podcast。正式 `src/data/podcast-work-map.json` 目前為 `[]`，未有核准相同作品映射，因此在審閱清單全部展開時會出現 **48 篇文章 + 25 集 Podcast = 73 筆**。數量本身是現況，不代表缺文章或多匯入文章；也不是發布資料庫真的有 73 篇文章。
- 25 集 `podcast-classifications.json` 目前仍全為 `proposed`；審閱模式可能展示候選，非審閱模式尚不能把未核准 Podcast 分類冒充正式主題標籤。
- **當前缺陷**：在 `/topics/psychology/` 這類已固定主題的頁面，清除表單篩選會把主題選單設成「全部主題」，但頁面標題仍是「心理與行為」，使清單誤顯全部作品。修正應保留路由主題；如要探索別的主題，明確導航到 `/topics/`，不可留著舊標題展示其他分類。

## 二、決定採用的內容呈現原則

1. **保留雙欄＋單欄的分工**：`文章與故事`／文章總覽用雙欄卡片，便於瀏覽封面；九大主題探索頁維持單欄作品卡，便於閱讀摘要、觀察文字與音訊版本。行動裝置自然落為單欄。待有權使用的正式圖片接入後，再做必要的視覺一致性精修，不為統一欄數而重做列表。
2. **主題頁固定主題，不讓「清除篩選」跳出頁面語意**：清除僅還原搜尋字、臨時系列篩選；主題由路由決定。另提供「瀏覽其他主題」入口。已在本 PR `WorkExplorer.astro` 做最小修復。
3. **同一作品一張卡片**：**只在作者核准 GUID ↔ work_id 是同作品媒介版本時**合併為一張 `UnifiedWorkCard`，標題與介紹沿用該作品已核准的文章資訊；卡片提供「閱讀全文」與「收聽 Podcast」兩個清楚的入口，沒有哪個媒介便不顯示哪個入口。
4. **Podcast-only 作品維持獨立卡**：顯示已確認的節目標題、介紹、收聽連結；若分類仍 pending，不為了把它塞入主題頁而猜主題／系列。已核准的凡思維單集即使沒有網站全文，也要能進凡思維的對應索引。
5. **不同作品仍需保留兩張卡**：即使主題、標題相近，若作者判定是延伸評論或獨立作品，只建立明確「相關閱讀／相關收聽」的連結，不強行以相似標題去重。既有 48 篇核准文章不可刪除或改分類。
6. **一集 Podcast 引用兩篇文章**：《鬼滅之刃》案例的 `GUID 05b69613-4296-4c7a-a205-5937639fb559` 在原文同時連到兩篇不同書面作品；目前 `mapSchema` 拒絕同一 GUID 重複映射。等作者決定「主要同作品版＋相關延伸」或核准多對一模型後，再按決議實作；不得將第二篇文章丟失。
7. **卡片共用視覺系統**：同字級層次、日期、系列／主次主題、可選取摘要、邊界與連結；文字版全文／Podcast 詳情的入口視覺清楚。不要整卡包在超連結內，讓摘要依然可選取。原文與 Podcast 文案不改寫；無權使用的封面不抓取、不假造。
8. **排序與搜尋沿用已驗收成果**：不重做 IG／Podcast 人氣快照或文章列表排序。作品層搜尋結果只合併正式確認的相同作品，且每種媒介可被搜尋命中；對 Podcast-only 需支援已核准分類。

## 三、驗收條件（等 Codex 正式做整合時）

- `/topics/psychology/` 進入頁面、搜尋關鍵字、清除篩選，標題／結果仍保留心理與行為主題；不突然列出全站 73 筆。換其他主題使用明確導覽。
- `/series/stories/` 保持雙欄文章列表；主題探索單欄；手機版不溢出。
- 取得正式作品映射後，Punch 等已核准的同作品書面與聲音版在主題探索中只有一張卡，兩個入口都可用；沒有對應媒介就不顯示空入口。
- 《鬼滅之刃》一集兩篇文章不損失任一篇文章；處理依作者核准決議，不能由標題自動決定。
- 25 集分類尚未核准前，不顯示虛假的已確認標籤；核准後凡思維 Podcast-only 如適用應出現在系列索引，非凡思維不強塞。
- 使用核准資料做邊界案例抽查（書文＋Podcast、只有文章、只有音訊、同集相關兩篇、短網址）；僅跑受影響的針對性測試與 check/build，保留截圖做 UI 驗收。無需重抓全文、RSS 或人氣資料。
