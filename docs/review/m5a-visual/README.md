# M5-A 視覺精修驗收（2026-11-14）

基底 PR #6，分支 `codex/m5a-visual-refinement`。依 docs/01–03；本輪僅合成資料、保留首頁五場景及既有分類／功能。等待作者視覺確認，不合併、不部署、不進 M5-B。

## 本輪調整

- 書架共用 Bookshelf / BookCover：桌機最多 176px 的 2:3 書封、紙張深度、輕抽出效果、細書架底板；手機雙欄。單本篩選不放大。首頁、作品館及作者頁共用。
- 詳頁桌機書封與介紹並列，書封最多 250px；手機自然堆疊。出版資訊分組、正式購買連結及世界入口置於介紹側；試讀與授權短篇保留閱讀欄寬。不提供假購買網址。
- 四本明示合成作品用於不同狀態／形式與多本排列。無真實作品新增；正式書封仍待提供，不以合成封面冒充。
- 文章與出版雙向入口以 `src/data/publication-relations.json` 單一映射維護；必須 approved:true 與有效 work_id，拒絕重複／未知識別。不以主題或標題推測。合成關聯僅連合成作品；清除測試資料時一併移除。
- 原有文章間 related_work_ids、作品 GUID 與 25 集 proposed 保持不變。

## 測試與限制

`npm run check`：0 errors / warnings / hints。`npm run build`：54 頁及 RSS／sitemap。`npm test`：35/35 通過，含既有分類、RSS、防未核准公開、匯入及連結測試；新增文章／出版核准關聯與雙向輸出測試。隔離建置既有測試也驗證正式書封、購買連結與授權全文的條件呈現。

瀏覽器實測：1440×1000、390×844 CSS viewport。桌機單本篩選書封寬176px；手機書架無水平溢出，已出版篩選顯示2本，與長篇形式交叉無結果時提示正常。點擊作品→文章→作品的路徑正確。封面抽出僅限 hover 裝置；CSS prefers-reduced-motion 停用抽出與過渡，鍵盤保留明確 focus-visible 框。減少動態的既有自動測試通過；本輪未重新做系統偏好切換實機測試。
