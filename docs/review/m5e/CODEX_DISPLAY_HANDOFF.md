# M5-E主要展示｜最終單批實作規格

## 1. 任務與唯一資料

直接接續PR #20，分支`prep/m5e-publication-display-20261115`。先fetch最新refs，讀AGENTS、CURRENT_STATE和START_HERE，再直接實作，不先交另一份計畫。

完整輸入已在`docs/review/m5e/PUBLICATION_DISPLAY_INPUT.json`。指定照片已在`public/images/author/jiang-zongfan.avif`。先執行`python3 scripts/check_m5e_inputs.py`，不需要ZIP、PPT、小說PDF、Canva、下載程式或新的外部服務。

本輪是M5-E主要展示工程，不是全階段M5-E；留言／私人聯絡／分析另批，M5-F全站驗收、M6部署另行授權。不可合併任何PR、部署、解除noindex或啟用付費服務。

## 2. 固定輸出與資料映射

沿用`src/data/publications.json`、`src/data/author.json`及現有`src/lib/publications.mjs`等執行入口。輸入JSON是內容契約，不要直接拿整份外層物件覆蓋strict schema。

正式七筆ID與slug完全相同：
- publication-tianqi-1／2／3
- publication-singularity-1／2
- publication-heart-reflection
- publication-data-storm

最小擴充模型以容納`description`段落陣列、具名`endorsements`、`recommendation_credits`、`award`、媒介分組links、版次日期／ISBN，以及`online`與`completed`兩種不同資訊。不要把網路完結等同紙本出版，亦不把完結小說標為連載中。保留原synthetic及公開核准保障，合成作品移到測試fixture，不生成正式demo頁。

只對本次七筆已授權展示的文案建立網站核准metadata；UI驗收與部署仍未批准。無值的publisher／series／order等欄位按schema省略，不創造出版商或年份。既有編輯短介、完整介紹、引言文字保持逐字，不自行潤稿。

## 3. 頁面顯示

保留既有書架層板、陰影、書封抽起效果、兩欄手機及reduced-motion。小說書架有正式封面；文章列表繼續文字卡。不要混改兩者。

書架每本僅顯示封面或既有文字標籤、標題、冊別／狀態、短介。按display_order排列，天啟I→II→III、智慧奇點上→下相鄰。保留既有形式／系列／狀態篩選並加入準確的網路發表狀態；七本不另增複雜分頁。

作品詳頁：
1. 書封與標題、短介、實際平台入口；桌機並排、手機上下。
2. 「作品介紹」依description自然段落排版。
3. 推薦摘句預設兩則，其他用原生details展開，不做輪播。保留姓名、原話、來源標示。只有列名的推薦者不可擅自寫引言或補現職。智慧奇點的介紹與推薦屬整部作品，標示作品層級，不冒稱下冊專屬梗概。
4. 系列閱讀順序、版本資訊、存在時的相關內容。無試讀／世界觀／推薦的區塊隱藏。

不上傳短篇全文、長篇全文、私人提案或PDF；資料未授權的world/excerpt/full_text保持不存在。數據風暴第一版只能作既有介紹的編輯依據。

## 4. 封面與照片：不再開蒐集／下載任務

六張封面用輸入中`cover.source_url`的既定官方遠端圖址，普通img、原比例、正確alt，必要時no-referrer；不要求先下載、建立圖床、代理或另搜素材。圖片失敗採既有文字式作品標籤，不留破圖，但失敗作品必須在驗收報告列明，不能稱封面已驗證。

數據風暴`cover.mode=typographic`是明確資料決定，使用既有文字標籤，不生成或冒稱出版封面。作者照片用repo內AVIF，640×960、完整直幅；不修臉、不裁圓形、不換背景。只在local asset路徑套用`/fansi-notes/`共用url helper，不能將外站HTTPS網址加base。
