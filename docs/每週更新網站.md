# 非工程師每週更新網站

你只需提供已核准的書面文章與公開連結，請 Codex 在新分支整理一次，再看預覽確認。不要把待發表全文交給公開 GitHub；「SOP 完成」仍不代表允許網站公開。Podcast 稿件與網站書面母稿分別核准。

## 1. 新增作品（合成示範）

可以對 Codex 說：

> 請在測試分支新增《三個傻瓜》的合成測試卡。作品 ID 為 demo-three-idiots，網址 demo-three-idiots，類型 longform，主題 reading。正文只寫「這是合成測試資料，並非作者原文。」核准版本 synthetic-v1、核准人 synthetic-fixture、核准日與示意發布日 2026-01-01T09:00:00+08:00。標示 synthetic: true、publication_status: demo、website_approved: true、written_master: ig-vocus。請提供本機預覽與 PR，不部署。

Codex 把內容放到 src/content/articles/ 的一份 Markdown；首頁最新文章、文章列表、搜尋及主題頁會一起更新。正式作品則須提供已公開或明確允許網站公開的書面母稿、永久作品 ID、核准署名／版本／日期與發布日，使用 published 和 synthetic: false。私有草稿不能先放進公開分支再隱藏。

## 2. 改標題、類別與網址

告訴 Codex「修改 demo-three-idiots 的標題／摘要／主題」，作品 ID 不變。要更改網址時，把舊 slug 加進 aliases，舊連結仍可到新頁。類型 fansiwei 是簡潔短篇；longform 是封面與章節目錄版。章節用 Markdown 的 ## 標題。related_work_ids 可指定延伸閱讀；featured_order 可安排首頁精選順序。

## 3. 補 Instagram／Vocus 連結

> 請替作品 demo-three-idiots 的 platform_urls 補上我提供的 instagram_url 與 vocus_url；核對作品 ID 後再填，不猜網址。

測試時只在隔離測試中使用 https://www.instagram.com/p/fixture/ 和 https://vocus.cc/article/fixture，這些不是作者的真實頁面。未提供連結時網站不顯示按鈕。正式連結須由作者提供。

## 4. 更新 Podcast 與配對

正式來源已設定於 src/data/podcast-config.json。請 Codex 執行 npm run sync:podcast；成功會更新 src/data/podcast.json 的公開標題、封面、介紹、日期與連結。失敗保留舊快取，不清空網站。RSS 的電郵、原始 XML、音訊檔與私稿都不儲存。

> 請同步 RSS，列出待配對的 GUID 與標題給我確認。先用合成 GUID demo-three-idiots-guid 和 demo-three-idiots 在隔離測試示範，不配對真實單集。

你確認後，Codex 才在 src/data/podcast-work-map.json 填入：

```json
[{ "guid": "demo-three-idiots-guid", "work_id": "demo-three-idiots", "approved": true }]
```

這段只示範格式；GUID 必須確實存在於測試單集中，不能直接貼入正式配對表。文章與單集標題可以不同。正式表目前是空白，不把真實單集配給合成文章。

RSS 目前未提供 open.spotify.com/episode/ 單集網址。你可從 Spotify 分享單集連結，交給 Codex 補入該 GUID 的 spotify_episode_url。之後同步會保留它；讀者點「載入 Spotify 播放器」才連線載入，未點時不載入 iframe。尚未補網址仍可走官方單集頁或節目頁。

## 5. 看預覽、測試與保存

請 Codex 執行 npm run check、npm run build、npm test，提供桌機／手機預覽、變更摘要與 PR。你確認後再決定合併；本階段沒有公開部署。進度以 Git commit 分段保存，切換對話時請讀 docs/開發進度.md 和 git log。

每日讀取工作已準備：合併到預設分支後，GitHub Actions 預計台灣時間 06:23 執行（可能延遲），也可手動 Run workflow。它只有讀取權限，產生 podcast-review artifact（最新資料與網站建置），不回寫分支、不部署。下載或請 Codex 檢查 artifact 後，再另提資料更新 PR；尚未合併前排程不會啟用。

## 單集直達連結補充

目前 25 集已核對 Spotify 官方頁的 RSS 單集路徑，以及 Apple 公開目錄的 episodeGuid、節目 ID 與 feedUrl，加入雙平台單集直達連結。核對紀錄見 docs/review/m3/episode-link-verification.json。RSS 同步會保留既有兩平台連結；新集尚未核對時明確顯示「節目首頁」。請 Codex 按相同識別碼核對新單集，不用標題猜配。文章 work_id 配對表仍獨立且未變更。
