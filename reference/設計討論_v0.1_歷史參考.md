## 1. 定位與設計原則

**定位**：兼具作者作品集、完整文章資料庫、Podcast 節目入口、原創小說／出版書展示及讀者交流的個人創作網站。

- 首頁具有記憶點，讓人樂於探索；文章頁優先服務閱讀。
- 使用者不必理解象徵插畫才能找到內容；文字選單、搜尋及一般連結始終可用。
- **作品是資料主體；文章、Podcast、IG 輪播、Vocus 是同一作品的不同呈現。**
- 未發表、未經核准的內容不可公開；不可自動臆造故事、作者經歷、引用與書籍資訊。
- 不要求作者每週將同一篇文章在四個地方手動重建；外部平台上架後由作者更新對應網址即可。

## 2. 全站導覽與資訊架構（Site map）

### 全站主導覽
`首頁｜探索文章｜凡思聲｜小說與出版｜關於作者`，搭配 `搜尋`、`聯絡`、`Instagram`、`Spotify` 外連入口。

### 分頁結構
- **首頁 `/`**：互動故事書 Hero、最新發布、文章精選、凡思聲、小說／出版、關於作者、聯絡、頁尾。
- **探索文章 `/articles/`**：所有文章，可依「形式／類型」與「主題標籤」篩選及搜尋。
  - **凡思維 `/articles/?type=fansiwei`**：心理、科學、歷史、反直覺觀點等短篇研究。
  - **深度文章 `/articles/?type=longform`**：書籍、影劇、哲學、人物與其他長篇。
  - **文章詳頁 `/articles/{slug}/`**：該篇正式完整書面定稿、插畫、來源、Podcast 與平台連結、相關作品及留言。
  - **主題頁 `/topics/{slug}/`**：同一主題的跨類型作品集合；類型與主題不能混為一談。
- **凡思聲 `/podcast/`**：節目介紹、最新單集、歷史集數、主題篩選、Spotify 節目連結。
  - **單集頁 `/podcast/{slug}/`**：介紹、官方播放器、對應作品／文章及相關集數；同一作品的資料以作品 ID 關聯，不複製全文資料。
- **小說與出版 `/works/`**：收藏書架、已出版作品、原創小說／短篇和系列作品。
  - **書籍作品頁 `/works/{slug}/`**：正式書封、出版資訊、故事簡介、可公開的試讀、系列順序、外部出版／購買連結、相關文章及讀者討論。
  - **獨立故事世界 `/works/{slug}/world/`**：有正式授權公開的世界觀、人物、番外／作品素材才顯示；沒有資料時不生成空頁。
- **關於作者 `/about/`**：確認過的作者簡介、醫師／作家背景、正式出版作品、創作年表、社群與合作入口。
- **聯絡 `/contact/`**：讀者私人來信、合作邀約、隱私說明與社群連結。

### 全站頁尾
網站品牌與作者署名、主題入口、Instagram、Spotify、Vocus、出版／個人作品連結、聯絡與隱私資訊。社群帳號及對應 URL 均從共用設定讀取，不能在每一頁硬編輯。

## 3. 首頁體驗（Desktop Hero）

### 故事與視覺
一本橫向展開的繪本位於畫面中央偏下，書頁外延成一幅連續地景。平面插畫是視覺主體，透過少量圖層景深、陰影與漂浮元素製造 2.5D 質感；畫面不是五張不相連的卡片，也不是必須操作才能進入的 3D 遊戲。

**五個互動場景**（場景暫名／主要點擊名稱）：
1. **思想的花園 → 凡思維**：植物、研究筆記、分岔線條，局部葉片微動；預覽短篇。
2. **聲音的房間 → 凡思聲**：溫暖燈光、聲波與收聽角落；預覽最新 Podcast。
3. **故事的長廊 → 深度文章**：書頁、閱讀長廊、電影與文學線索；預覽長篇。
4. **想像的國度 → 小說與出版**：從書頁延伸的門、書架、異世界剪影；預覽出版作品。
5. **作者的書桌 → 關於作者**：筆記本、筆、信封；進入作者與聯絡空間。

### 互動狀態
- **初始**：主標題與品牌可見，五個場景本身有足以辨識的文字提示；另有明確「探索作品」入口。
- **游標移動**：前後景小幅視差、紙張陰影變化，幅度克制。
- **Hover／鍵盤聚焦**：目前場景微亮並產生單一代表動作，浮出清楚的分類名稱、短說明與 1–2 個真實作品預覽；不可顯示尚未公開的作品。
- **Click／Enter**：短暫收束／淡入相對應頁面；轉場不應阻擋正常導覽或瀏覽器返回。
- **向下捲動**：Hero 收束，漸入編輯式內容列表；不得強制滾動、長時間鎖住畫面或攔截閱讀。
- **手機／平板**：保留簡化插畫，五個入口改為大尺寸點擊區或可讀的分區清單，不依賴 Hover；圖層動態更少。
- **無障礙**：鍵盤可聚焦每個入口，完整文字標籤，對比足夠；尊重 `prefers-reduced-motion`，關閉動態後仍能正常使用；圖片有描述性替代文字。

### 首頁 Hero 之下的模組順序（草案）
最新發布 → 探索文章／主題 → 精選長篇與凡思維 → 凡思聲最新單集 → 出版書架 → 作者介紹短區塊 → 讀者來信入口／頁尾。

## 4. 文章頁的兩套閱讀模板

### 共通
- 正文以核准的 **IG／Vocus 共用書面母稿**呈現；網站只改排版，不擅改寫內容。
- 明確呈現標題、作者署名、分類、日期、封面、完整文字與必要來源。
- Podcast 可選擇嵌入對應的 Spotify 官方播放器；未發布或無單集時不顯示空播放器。
- 可選擇附上「觀看 IG 輪播」「前往 Vocus」及「分享此篇」；外連 URL 未填時隱藏。
- 文章下方有相關作品推薦與公開留言區。
- 長文提供可折疊的章節目錄、細緻閱讀進度條；正常捲動與複製文字不能受動畫干擾。

### 深度文章（Longform）
偏沉浸：較大的主題插畫、寬鬆的開場、舒適的標題層次；正文建議桌機閱讀欄寬約 680–760px；可以插入有敘事或知識功能的獨立圖片，不重複濫用封面。

### 凡思維（Fansiwei）
偏精簡：標題與封面更集中，快速進入問題、研究與故事；必要時提供論文、年份、研究資料來源區（正文後方的獨立區塊）。研究資訊可展開查看，不把論文註記寫成破壞敘事的說教。

## 5. 凡思聲 Podcast 頁
- 節目首頁：節目介紹、最新單集、集數與主題索引、外部訂閱／平台連結。
- 單集頁：正式單集名稱、可編輯封面輸出的圖像、介紹、播放器、關聯書面文章、延伸閱讀。
- **Podcast 完整逐字稿是獨立核准的長版母稿**，不與 IG／Vocus 書面母稿混淆。網站預設公開完整書面文章；逐字稿是否公開另由作者決定。
- Spotify 已發布單集可利用官方嵌入與／或公開資訊連結；不要求網站自行託管音檔。

## 6. 小說與出版：收藏書架＋獨立故事世界
- 作品區主頁如一座有層次的紙本書架，使用**真實書封**，依「出版書籍」「原創小說／短篇」「系列作品」瀏覽；不同作品可有不同分類。
- Hover：書本輕微向外抽出／傾斜；Click：展開作品詳頁。手機改為點擊，避免難以操作的視差效果。
- 作品詳頁：正式書封、作品簡介、出版資訊（經作者核准）、系列與閱讀順序、可公開試讀、外部官方網站／購書連結、相關文章與讀者留言。
- 個別作品可有不同的場景主題與色彩，但保留一致的導覽、字體、內容欄位和操作方式；不可擅造作者未公開的世界觀、人物或故事素材。
- 可逐步支援小說專屬世界觀、人物、番外，但**第一版不以完整百科或互動遊戲為前提**。
- 既有待確認的作品素材：《天啟》《智慧奇點》《心靈倒影》；網站使用前需核對真實書封、書名版本、簡介、出版連結、作者公開順序。

## 7. 作者頁與聯絡頁
### 作者頁
- 雙品牌框架：網站標示《凡思筆記》，作者頁強化正式公開署名、醫師與作家身分、出版作品、創作脈絡。
- 使用由作者核准的自傳／照片／經歷，不自動拼裝私密個人資訊或杜撰訪談、臨床事件。
- 「創作年表」以作者可核對的真實里程碑與作品素材組成，可輕微捲動揭露；可省略尚未確認的年份。
- 出版與演講／合作資訊獨立呈現，避免像求職履歷表。

### 留言與來信
- **公開留言**：文章／出版作品頁下方，支援討論、作者回覆、審核／封鎖垃圾訊息。不能要求一般讀者一定要有 GitHub 帳號才能留言。
- **私人聯絡**：聯絡表單區分讀者來信與合作邀約；標示聯絡資料用途及隱私事項；需防垃圾訊息、避免公開展示個人郵件。
- **技術未定**：GitHub Pages 為靜態網站，留言與表單需適當外部服務或後端；在開發階段比較可用性、讀者門檻、成本、資料控管與管理負擔後，再由作者選擇。

## 8. 資料模型：一份作品，多種媒介

一篇「作品」應有獨立識別碼，至少包含下列資料（**欄位規格，不是程式碼**）：

| 類別 | 欄位 | 原則 |
|---|---|---|
| 身分 | `work_id`, `slug`, `title`, `subtitle`, `author_public_name` | 作品 ID 持續固定；標題可改、URL 轉址需考慮 |
| 分類 | `content_type`, `topic_tags`, `related_works` | 類型、主題、相關作品分離 |
| 內容 | `written_master`, `podcast_master`, `summary`, `sources` | 書面與 Podcast 雙母稿，分別核准 |
| 視覺 | `cover_art`, `interior_images`, `book_cover`, `podcast_cover` | 真正圖片來源、授權與適當用途 |
| 平台 | `instagram_url`, `vocus_url`, `spotify_episode_url`, `canonical_url` | 可空；未發布時不顯示不存在的連結 |
| 工作流 | `draft_status`, `approved_version`, `publication_status`, `published_at` | 私人草稿與公開內容分離 |
| 管理 | `canva_design_ids`, `last_editor_note`, `updated_at` | 供工作台使用，避免暴露在公開頁面 |

**發布規則**：公開網站只讀取經作者核准、且標示網站可公開的書面內容。Podcast、IG、Vocus 的外部上架不由網站自動執行；作者在各平台發布後，更新對應連結，網站即可同步顯示。不可把尚未發布的五篇備稿自動公開。

**與既有 SOP 相容**：Podcast 完整母稿與 IG／Vocus 共用書面定稿獨立；網站正文採後者。IG 圖卡、Vocus、網站文字更動時檢查版本一致性；Podcast 不因書面稿修改而自動重寫。Canva 的可編輯設計仍保留在 Canva。

## 9. 建議技術方向（供 Codex 評估，不是本階段的實作指令）

- **預設候選**：Astro 靜態內容網站、GitHub 儲存版本、GitHub Pages 或其他適合靜態部署的平台。
- **網站內容**：以結構化內容檔管理已核准作品與分類；讀取內容時自動生成首頁列表、文章頁、Podcast 頁與作品關聯。
- **搜尋**：可在不建後端的前提下先做站內搜尋／篩選。
- **互動**：CSS／輕量 JS／SVG／分層插畫優先；只有明顯提升體驗的地方才引入較重技術。
- **留言／聯絡**：須經第三方服務或後端處理；不得直接把帳密、API 金鑰、未發布草稿放進公開 Repository。
- **SEO／分享**：每頁獨立標題、摘要、分享縮圖、基本結構化資訊、sitemap、正確導覽連結；搜尋引擎可讀到正文。
- **部署**：核准的網站公開資料更新後可自動部署；部署不等同跨平台發布。

## 11. 最低驗收標準

1. 第一次開啟首頁，讀者在無需互動教學下知道「凡思筆記」與作者是誰，以及如何進入五大領域。
2. 滑鼠移動與場景 Hover 有辨識度；關閉動畫、使用鍵盤或手機時，所有入口依然可用。
3. 深度文章與凡思維有明顯不同的閱讀版型，但文字來源均可追溯到正式書面母稿。
4. 五篇待發表作品可作為**本機／預覽環境的測試內容**： 《三個傻瓜》《說不完的故事》《奧德賽》《25 號宇宙》《全世界都在吵》。公開網站只展示作者已批准發布的內容。
5. 每一作品可關聯 IG／Vocus／Spotify URL，未填的連結不顯示；Podcast 無需重新上傳音訊。
6. 書架展示真實書封，並支援進入作品介紹與正式外部書籍網站；未核准的試讀和世界觀不得生成。
7. 讀者能搜尋與瀏覽分類、使用一般文字導覽、返回上一頁；小螢幕排版無橫向溢出。
8. 留言及聯絡資料有必要的基本安全、審核與隱私安排；GitHub Pages 本身不得被誤認為已有後端功能。
9. 網站內容更新後能重新部署；GitHub Repository 不包含私人草稿、音訊原檔、機密資訊或未核准發布的作品。
10. 不修改使用者現有 Canva 母版、已確認文章或其他 GitHub 專案。

## 12. 下一輪應先確認的設計問題
